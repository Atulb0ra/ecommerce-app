The project also includes a separate admin panel for managing products and orders.

# What it does

### 🛍️ Product Browsing

Users can browse available products and view product details.

### 🛒 Cart Management

Users can add products to their cart, update quantities, and remove items.

### 🔐 User Authentication

Users can register and log in securely using JWT-based authentication.

### 📦 Order Management

Users can place orders and view their orders.

### 💳 Online Payments

Stripe is integrated to handle secure online payments during checkout.

### 🛠️ Admin Panel

Administrators can manage products and orders through a separate admin dashboard.

# How it works

1. Users browse products available on the platform.
2. Products can be added to the shopping cart.
3. Users authenticate before accessing protected features.
4. Users proceed to checkout and make payments using Stripe.
5. Orders are stored and managed through the backend.
6. Administrators can manage products and orders from the admin panel.
